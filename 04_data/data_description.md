# Data Description

## 1. General Overview & Reduced Setup
Our project evaluates anomaly detection performance using a **zero-shot** approach via the WinCLIP framework. Because the model relies on pre-trained vision-language features rather than being explicitly trained on these specific datasets, **we do not utilize standard train/validation splits**.

Instead, the model is evaluated directly on the designated `test` partitions (or the entirety of datasets lacking formal splits) to measure its generalized ability to distinguish between normal and anomalous samples. 

---

## 2. Dataset Descriptions

### A. MVTec AD (Anomaly Detection)
* **Description:** A comprehensive industrial dataset containing high-resolution images of 15 different object and texture categories (e.g., bottle, cable, hazelnut, leather, wood). 
* **Data Split:** We evaluate solely on the provided `test` directory, which contains both "good" (normal) samples and various named anomaly categories (e.g., "scratch", "broken", "contamination").
* **Masks:** Ground truth pixel-level masks are provided for all defective images.

### B. MVTec AD Synthetic
* **Description:** A custom robust evaluation dataset created to simulate unpredictable real-world factory conditions. This was generated by mirroring the original MVTec AD directory structure and applying a combination of dynamic environmental degradations.
* **Degradations Applied:**
    * **Random Blur:** Applied Gaussian blur using a random sigma uniformly distributed between 1.0 and 3.0 to simulate out-of-focus or motion artifacts.
    * **Random Darkness:** Applied a random brightness multiplier between 0.3 (very dark) and 0.8 (slightly dim) to simulate fluctuating factory lighting.
    * **Random Grain/Noise:** Added Gaussian noise with a mean of 0 and a standard deviation randomly selected between 15 and 40 to simulate sensor ISO noise.
* **Masks:** Ground truth masks were strictly preserved and copied over exactly without any applied degradation.

### C. Casting Data
* **Description:** An industrial dataset containing top-view images of cast manufacturing products (specifically submersible pump impellers).
* **Data Split:** Evaluated on the test split, containing `ok_front` (normal impellers) and `def_front` (defective impellers with surface scratches, holes, or deformities).

### D. Magnetic Tile Defect Dataset
* **Description:** A dataset containing images of magnetic tiles collected under varying lighting conditions.
* **Data Split:** The dataset is structured by defect type (Blowhole, Crack, Fray, Break, Uneven) alongside normal images classified as `Free`. We evaluate on the entire dataset, distinguishing `Free` images as normal and all others as anomalous.

---

## 3. Preprocessing Pipeline
All images undergo standard OpenAI CLIP preprocessing before being passed to the model:
* **Resizing:** RGB images are resized to 224x224 pixels using Bicubic interpolation.
* **Normalization:** Image tensors are normalized using standard CLIP statistics: Mean `(0.4814, 0.4578, 0.4082)` and Standard Deviation `(0.2686, 0.2613, 0.2757)`.
* **Mask Preprocessing:** Ground truth anomaly masks are converted to single-channel grayscale, resized to 224x224 using Nearest Neighbor interpolation to preserve binary edges, and converted to tensors. 
* **Dynamic Weighting:** Prior to standard transforms, all inputs are evaluated via custom OpenCV heuristics to extract dynamic degradation weights (Clean, Blur, Dark, Bright, Grain).
